TRUTH #2 · STATIC IP KA SACH
#103

Naya server chahiye hi nahi tha. Paise bach gaye.

Poora naya VPS setup ban chuka tha (rsync + venv + systemd + Caddy HTTPS) — phir asli order test se prove ho gaya ki zaroorat hi nahi. Migration DROP. Ye raha jo seekha:

kite Whitelist sirf ORDER pe
Kite IP-whitelist sirf order placement pe lagta hai. Read calls (profile/margins/order_margins) IP-gated nahi.
trap "margins pass" ≠ "order chalega"
Naye IP se order_margins pass ho gaya — par asli place_order → PermissionException. Ek galat conclusion se bacha, asli SBIN order ne pakda.
dhan DATA ko whitelist nahi chahiye
LTP, candles, live WebSocket — teeno non-whitelisted IP se chale. Sirf Dhan ORDER IP-gated (DH-905).
⚠️ 7-din lock Dhan IP badla to fansa
Dhan ka static-IP ek baar badla to 7 din aur nahi badal sakte. Casually reversible NAHI.
ipv4 Kite ko bhi IPv4-force chahiye
Sirf Dhan nahi — VPS ka IPv6 outbound Kite pe bhi reject hua, chahe IPv4 whitelisted ho. Same getaddrinfo fix dono pe.
data Kite pe data add-on nahi
kite.ltp() → Insufficient permission. Isi liye architecture: data Dhan se, order Kite pe.
🤝
Final arrangement: Arsalan ko static IP ki majboori nahi (Hostinger ka IP already Kite console me + IPv4-force). Static IP sirf Dhan-order wale (bhai) ko chahiye. Kite ↔ Dhan whitelists bilkul independent hain — network-trace se confirm.
